About:

This site shows the results of the Clang-Tidy Integration Tester (CTIT). CTIT takes a clang-tidy check, usually one from an LLVM pull request, runs it on a set of open-source C and C++ projects, and records every warning it reports. The results help find false positives, crashes, and slowdowns in a check before it lands in LLVM.

Each run is stored as a JSON file in $repository, and this site is rebuilt whenever new results are committed there.

Index:

The index has one table per pull request and check, with the most recently tested first. Runs of a check on LLVM main, without a pull request, are listed under "main". Each row is one run, newest first, and runs on different runner architectures share a table.

The project columns show how many warnings the check reported in each project. The number in parentheses is the change since the previous run in the same table: red for more warnings, green for fewer, and gray for no change. A red background marks a run or project that did not complete; hover over it to see its status.

Verdicts:

In each run, an AI model labels every warning as a true positive (TP) or a false positive (FP). The labels are only a hint and can be wrong. Warnings the model did not label count as unclassified.

Baseline:

A run started with /baseline also runs the check on the same LLVM revision without the pull request's patch. Its run and project pages then show which warnings the patch adds (new) and which ones it removes (gone).

Source links:

Links to warnings point to the project commit that CTIT's testers/projects.json pinned when the run started, which is the code the check ran on.

Timings:

Once a day, CTIT runs every clang-tidy check on every test project with clang-tidy's check profile enabled. The timings page charts how long the checks took over time. You can pick the projects to sum over and filter the checks, and a filter for a single check gives that check a link of its own. Each day is stored as a JSON file under timings/.

If a run recorded a check profile, its run page shows where its check would rank by check time among all checks of the latest daily run.

Data:

A machine-readable summary of all runs is at data/runs.json.

To test your own clang-tidy change, follow the instructions in the CTIT repository.
