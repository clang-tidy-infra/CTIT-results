About:

This site shows the results of the Clang-Tidy Integration Tester (CTIT). CTIT runs a clang-tidy check, usually from an LLVM pull request, against a corpus of open-source C and C++ projects and records every warning it produces.

Each run is stored as a JSON file in $repository. This site is regenerated every time a new run is committed there.

The index groups runs by pull request and check. Each project column shows the number of warnings, and the number in parentheses is the change from the previous run of the same group: more warnings in red, fewer in green, and no change in gray. Runs from different runner architectures are listed together. A red background marks a run or project that did not complete; hover over it to see its status.

TP and FP verdicts are produced automatically by an AI model and are only a hint. Warnings without a verdict are listed as unclassified.

For runs started with /baseline, the run page and project pages show which warnings are new compared with the unpatched LLVM main branch, and which baseline warnings are gone.

Source links point to the project commit listed in CTIT's testers/projects.json when the run started.

The timings page follows the daily run of every clang-tidy check over all test projects, summed over the projects you choose, and each check has a page of its own. Each day is stored as a JSON file under timings/. Runs recorded with a check profile show on their page where their check would rank by check time among the checks of the latest daily run.

A machine-readable summary of all runs is available at data/runs.json.

To test your own clang-tidy change, follow the instructions in the CTIT repository.
